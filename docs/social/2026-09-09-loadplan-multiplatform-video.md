# 柜算 LOADPLAN 首条多平台视频脚本

## 核心定位

- 产品名：柜算 LOADPLAN
- 主标题：**免费开源的外贸装柜工具：一柜货装不装得下，先算再发**
- 一句话信息：填写货物外包装尺寸、数量和重量，先在本机估算装柜数量，查看 3D 摆放图并导出报告。
- 可信依据：免费开源；网页和桌面版可离线计算；数据默认不上传；支持 3D 查看、Excel、PDF、PNG 导出。
- 表述边界：使用“估算”“当前方案”“用于沟通和预判”；不要说“最优方案”“保证装下”“替代现场装柜”。

## README 功能口径（拍摄时按此顺序展示）

1. 选择 20GP、40GP 或 40HQ；柜内尺寸、最大载重和柜门尺寸均可按实际设备修改。
2. 为每种货物填写外包装长宽高（mm）、数量、毛重（kg），并设置能否转向、能否叠放、最多层数、是否只能放底层；支持纸箱、木箱、整托、木架/裸装机器的外接长方体估算，以及直立/横放圆柱货物。
3. 点击“计算装柜方案”，查看已装数量、未装数量、已装毛重和空间使用情况；一次计算一个柜，最多 30 种规格、合计 1,500 件。
4. 点击“比较装柜方案”查看另一种当前摆法；旋转、放大 3D 图，切换俯视、侧视或逐层查看，并点击货物查看位置明细。
5. 导出 Excel、PDF，或保存当前 3D 图片；Excel 明细可编辑，PDF 用于查看和打印。
6. 强调无需注册；网页直接使用，Windows/Mac 单机版可离线计算；货物数据默认在浏览器或电脑本地处理。

### 必须说清的边界

“当前方案”是几何和规则估算，不是全局最优证明；“未装入”不等于绝对装不下。摆放图用于发货前估算和沟通，不等于人工装柜顺序，也不包含现场承重、绑扎、搬运路径和运输动态确认。

## 录屏准备

使用 Recordly 录制浏览器窗口或桌面版窗口。录制前关闭通知、把浏览器缩放调到 110% 至 125%、使用无客户信息的内置样例。原始素材使用 1920 x 1080、30 fps；竖版剪辑时只展示当前操作区域，不能把完整宽屏界面缩小塞进竖屏。

录制时每段单独开始和结束，鼠标在点击前停 0.5 秒，点击后停 1 秒。以下素材可同时供三个版本使用：

1. `01-result-overview.mp4`：默认样例的已装、未装、空间利用率和 3D 图，8 秒。
2. `02-cargo-input.mp4`：显示三个货物规格的尺寸、数量、重量和摆放限制，8 秒。
3. `03-calculate.mp4`：点击“计算装柜方案”，等结果稳定，6 秒。
4. `04-3d-orbit.mp4`：旋转、放大 3D 装柜图，切到俯视，10 秒。
5. `05-layer-detail.mp4`：筛选层数或点击一个货物，显示位置明细，8 秒。
6. `06-compare.mp4`：进入比较装柜方案，选中一个方案，8 秒。
7. `07-export.mp4`：点击导出 Excel 或 PDF，停在保存窗口打开前后的产品界面，6 秒。
8. `08-landing.mp4`：回到品牌和结果界面，留 3 秒作为结尾底图。
