# 纸箱装柜模拟器 v0.1

用户已批准：数据模型 → 简单装载结果 → 3D 查看器 → 可替换的装柜算法与独立校验。

## 范围
普通干货柜、规则纸箱、单柜多规格混装。中文界面，模拟数据明确标注。
20GP / 40GP / 40HQ 预设仅作参考，可编辑内尺寸、门宽高、最大载重。
浏览器本地使用，不上传业务数据、不需要数据库或账号。

## 坐标与数据
内部毫米、千克。X 从柜内最深处向柜门，Y 沿柜宽，Z 向上；位置为最小角点。
Cargo：id/name/size{x,y,z}/quantity/weight/rotation('upright'|'free')/maxLayers/color。
Container：id/name/size{x,y,z}/door{width,height}/maxWeight。
Placement：boxId/cargoId/containerId/position/size/weight/layer/stackId。
PackingResult：schemaVersion:1/container/cargo/placements/unpacked/strategy/validation。

## 计算边界
首版采用原创保守同规格堆垛＋平面排列启发式，尝试多种货物排序/摆放方向。
每垛相同规格和朝向、底部完整支撑；不跨规格向上叠放。
遵守最大层数、总载重、可用空间、纸箱按摆放朝向通过门宽高的必要条件。
柜门检查不代表完整运动路径验证。不模拟纸箱压溃、绑扎、重心与运输动态。
结果只能称“当前方案未装入”，不声称最优。分层查看不是经验证的装载操作顺序。
计算器与 Three.js 解耦，未来可通过适配器接入 Python 或 Java 开源求解器。

## 界面
清爽工业工具风格：浅灰画布、白色表单、墨绿主操作、低饱和 SKU 配色。
顶部品牌/本地状态/导入导出；左侧柜型和货物清单；右侧统计/3D/结果清单。
表单编辑后标记结果过期，过期结果禁止导出；点击计算才更新。
3D 支持自由旋转缩放、俯视/侧视/复位、柜壁、层数筛选、点击纸箱详情。
输入验证明确显示；WebGL 不可用仍可计算和查看结果表格。
JSON 导入/导出采用有版本的完整输入结构与独立验证；PNG 输出当前视图。

## 验收
手算案例、满柜、不能装入、旋转、载重、支撑、堆叠、非法输入、篡改结果校验。
浏览器验证编辑/计算/选择柜型/分层/导入导出/移动端及错误输入。
公开部署需在本地结果可审查后再处理。
