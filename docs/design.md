# 纸箱装柜模拟器 v0.1

用户已批准：数据模型 → 简单装载结果 → 3D 查看器 → 可替换的装柜算法与独立校验。

## 范围
普通干货柜、规则纸箱、单柜多规格混装。中文界面，模拟数据明确标注。
20GP / 40GP / 40HQ 预设仅作参考，可编辑内尺寸、门宽高、最大载重。
浏览器本地使用，不上传业务数据、不需要数据库或账号。

## 坐标与数据
内部毫米、千克。X 从柜内最深处向柜门，Y 沿柜宽，Z 向上；位置为最小角点。
Cargo：id/name/size{x,y,z}/quantity/weight/rotation('upright'|'free')/maxLayers/color。
Container：id/name/size{x,y,z}/door{width,height}/maxWeight。
Placement：boxId/cargoId/containerId/position/size/weight/layer/stackId。
PackingResult：schemaVersion:1/container/cargo/placements/unpacked/strategy/validation。

## 计算边界
首版采用原创保守同规格堆垛＋平面排列启发式，尝试多种货物排序/摆放方向。
每垛相同规格和朝向、底部完整支撑；不跨规格向上叠放。
遵守最大层数、总载重、可用空间、纸箱按摆放朝向通过门宽高的必要条件。
柜门检查不代表完整运动路径验证。不模拟纸箱压溃、绑扎、重心与运输动态。
结果只能称“当前方案未装入”，不声称最优。分层查看不是经验证的装载操作顺序。
计算器与 Three.js 解耦，未来可通过适配器接入 Python 或 Java 开源求解器。

## 界面
清爽工业工具风格：浅灰画布、白色表单、墨绿主操作、低饱和 SKU 配色。
顶部品牌/本地状态/导入导出；左侧柜型和货物清单；右侧统计/3D/结果清单。
表单编辑后标记结果过期，过期结果禁止导出；点击计算才更新。
3D 支持自由旋转缩放、俯视/侧视/复位、柜壁、层数筛选、点击纸箱详情。
输入验证明确显示；WebGL 不可用仍可计算和查看结果表格。
JSON 导入/导出采用有版本的完整输入结构与独立验证；PNG 输出当前视图。

## 验收
手算案例、满柜、不能装入、旋转、载重、支撑、堆叠、非法输入、篡改结果校验。
浏览器验证编辑/计算/选择柜型/分层/导入导出/移动端及错误输入。
公开部署需在本地结果可审查后再处理。

## v0.2 标准案例与算法比较
新增 7 个有独立手算依据的标准案例及 450 箱虚构业务样例。业务样例不设最优预期，只验证规则。
Worker 支持 pack / compare / suite；当前输入比较限时 15 秒，全套案例在独立 Worker 中限时 30 秒，不改变编辑输入。
compareAlgorithms 为两算法分别复制相同输入，独立计时并重新校验结果及输入一致性。失败结果保留诊断且禁止导出。
MaxRects 使用 MIT maxrects-packer 2.7.3，固定单个柜底，不自动扩柜。4 种排序 × 3 种朝向偏好 × 2 种排布逻辑共 24 次尝试，择优保留已装体积。
二维排布前统一转换为整数网格，通常精度 1e-6mm；自适应尺度保证坐标不超过 1e12，柜底向内、箱底向外量化，吸收整数附近乘法舍入噪声。跨度超出可保留范围时报错，不能假装有效。输出使用原尺寸和还原的毫米坐标，不修改独立校验器。
比较表支持切换 3D 和导出来源；输入修改后标过期，清除标准案例身份，避免修改后的货物冒充手算标准结果。单次耗时不是性能基准，不保证开源算法更优。

## 下一阶段：托盘与装载规则

### 货物形状边界

横放与木包装增补：shape 增加 cylinder-x/cylinder-y/wood-box/wood-frame。横放使用 cylinderDiameter、cylinderLength 表达实际圆柱，size 表达含支架的占位；两套算法只接受固定轴向，不自动水平旋转，最多一层。独立校验检查形状尺寸、朝向和地面支撑。3D 归一化几何保持占位范围，实例化渲染继承选择/分层/导出/资源释放逻辑；木构件厚度、支架样式只作示意，不提供真实承重或固定结构。历史直立模块中的“未支持横放”由本段更新。

2026-09-09 实施：新增 `shape: cylinder` 直立圆柱模式，`size.x = size.y = 直径`、`size.z = 高度`；仅允许 upright，不得同时标记 pallet。排布与独立碰撞检查仍采用方形包络，同一圆柱上下同轴对齐，不声称交错排列或圆形空间优化。Three.js 使用实例化圆柱几何并按原机制释放资源；混装数量按件统计，占位利用率明确区别于实际圆柱体积。圆柱未明确 stackable=true 时默认禁止叠放。独立校验新增叠放、底层与每垛重量检查。后续文本中关于圆柱精确排列的限制仍适用。

长方体纸箱、木箱按外部尺寸计算；不规则货物若已有长方体包装，继续按包装外尺寸计算。裸装机器或不规则木架允许用完全包住货物的最大长方体做保守估算，并配合禁止叠放、只能底层和承重限制。桶、卷材、管材的圆柱排列、可套叠货物、凹槽嵌入和真实异形碰撞不在当前精确模型内；界面应明确显示“按外接长方体估算”。

当前版本定位为纸箱散装装柜的空间估算工具。托盘、易碎货物、局部承重、预留间隙和现场装载顺序尚未实现，界面不得把这些能力描述为已经支持。

下一阶段增加货物形态“纸箱 / 托盘货物 / 整托货物”。托盘货物以托盘连同货物的整体长、宽、高、总重量参与排布，同时保留托盘重量和货物重量字段，便于结果解释。新增规则字段：是否允许叠托、是否允许上方放货、是否只能放底层、托盘最大承重。

装载约束分为四层：

1. **整体限制**：集装箱总载重、货物整体尺寸、柜门必要宽高。
2. **摆放限制**：不可倒置、不可侧放、只能底层、禁止上压、允许或禁止叠托。
3. **承重限制**：托盘最大承重、上方货物重量、易碎货物不得承受上方重量。纸箱抗压能力必须由用户明确提供，未知时不自动推断。
4. **空间预留**：用户可分别设置货物之间、货物与柜壁、货物与柜门的最小间隙。计算时向外预留，不能为了多装而缩小货物尺寸。

结果需要说明每件未装货物的具体原因，例如“柜门宽度不足”“超过总载重”“只能放底层但底层空间不足”“托盘禁止叠放”或“预留间隙后空间不足”。推荐方案只能依据当前规则下的装入数量，不能替代现场确认。

现场装柜顺序和搬运路径另列后续阶段：当前的层数与位置只表示几何布局，不表示人工、叉车或托盘车的实际操作顺序。实现该阶段前需要收集柜门方向、装卸设备、通道需求、允许回转空间和真实装柜记录。
