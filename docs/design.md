# 纸箱装柜模拟器 v0.1

用户已批准：数据模型 → 简单装载结果 → 3D 查看器 → 可替换的装柜算法与独立校验。

## v0.3.0 当前实现

全局矩形界面统一直角：面板、弹窗、按钮、输入框及提示容器的圆角为 0，保留圆形进度标识、圆点和椭圆徽标。Excel 导入空状态使用 620px 上限的紧凑弹窗，标题与居中上传区分组，选择文件使用橙色主按钮；加载工作簿后展开为完整映射和预览布局，显示文件名并支持拖入文件。

常驻导航增补：左侧货物与柜子两组入口不随步骤隐藏，基础组合模式直接选择并弹出对应编辑器，Excel 也使用独立模态弹窗。柜子弹窗可配置单柜、指定柜型清单或自动估算候选；完成时检查配置，Esc 可关闭。混装选择单一产品先进入保留规格确认，未确认不删除原清单。顶部标题改为“计算步骤提示”，仍保留三步当前状态；左侧底部计算按钮始终可用（计算及导出期间锁定）。

当前货物录入交互：顶部三步导航单行居中，左侧保留货物摘要、两种组合方式及橙底白字的 Excel 导入按钮。移除单独的“编辑货物”和“载入示例”入口，标题后显示浅色选择提示。组合方式与柜子计算方式只在左侧选择，弹窗仅编辑所选模式；完成按钮位于内容末尾水平居中，Esc 关闭。初始货物清单为空，新增规格的名称、尺寸、数量和重量留空，柜型标准参数保留。右侧货物汇总表始终保留，不使用强调线；输入变更后的旧装载结果仍标记过期。

指定多柜采用统一柜型列表，每行下拉选择柜型、填写数量、展开查看或调整参数。切换或新增柜型自动带入预设内尺寸、柜门和载重；所有行均可删除，至少保留一行。删除首行会将后续行提升为首行，计算顺序与界面列表一致。柜子设置完成只校验柜型参数，货物校验在完成货物编辑和计算时进行。

桌面操作采用“整理货物 → 设置柜子 → 查看方案”三步提示，保持左右分屏。左侧导航常驻，右侧在未计算时显示货物与柜型摘要，计算后显示整批结果和全部柜子的预览。初始不自动计算，步骤切换保留输入。货物校验失败时展开首个有问题的规格，数字字段就近显示范围错误；Worker 成功后进入结果，失败时保留设置。返回修改时保留右侧上次预览并标记为过期，修改后必须重算。

整理货物步骤内提供货物组合模式：单一产品装柜或多种产品混装。单一模式限制一条规格，Excel 导入默认替换并拒绝多规格结果；混装模式开放添加规格和多型号导入。Excel 按当前模式校验，不能将多个型号静默塞入单一产品流程。

结果页保留整批汇总、所有柜子的独立 Three.js 场景、当前柜明细和算法比较；算法比较位于主预览之后。导出入口只出现在结果步骤，展开后选择格式和范围，OBJ 框架及材质设置仅在选择 OBJ 时展示。首屏与柜型步骤不显示禁用的导出按钮或旧统计。

本段描述当前能力；后续 v0.1/v0.2 及“下一阶段”内容保留为设计历史。

- `cargoModel.ts` 统一手填与 Excel 的形态切换、本体尺寸及占位推导。`Cargo.size` 保持算法包络；新增本体、支撑、型号、原始单位、序列号和工作表来源字段。圆柱由直径与轴长生成包络，支撑开启时可扩展整体尺寸。形态、装载单位与支撑分别表达。
- `CargoEditor` 按形态展示字段；包装、底座或支架计入装运毛重。切换形态会重新计算单柜结果，其他编辑保留手动重算；旧图明确标示过期，校验失败或过期不能导出。
- `excelImport.ts` 与懒加载导入面板在本机读取 `.xlsx`。支持工作表/表头/数据行选择、字段映射、mm/cm/m 和 kg/g/t 换算、组合或分列尺寸、圆柱尺寸、含支撑占位、预览修正、筛选及选中行批量补充、保存本机映射及空白模板。自动识别只给建议，缺失重量不填零；同型号不同尺寸或规则不合并；序列号保留文本及前导零。
- 单柜 `PackingResult.schemaVersion=1` 保持兼容；新增整批 `FleetResult.schemaVersion=2`，保留原始货物、配置、逐柜结果和最终剩余。`fleet.ts` 复用单柜求解器，按配置顺序分配。每柜货物数量是该柜实际分配量，未装入在整批层统一记账，不把整批货物重复复制到每柜。
- 指定多柜支持混合柜型与独立尺寸、门、载重和间隙设置；柜型预设与实际柜号分开，结果编号为 C001 等。自动模式按选定柜型逐柜试算，装完、无进展或触达预算即停止。逐柜启发式不保证最少柜数，不计算运价或自动混选柜型。
- 整批校验重跑每柜独立校验，核对原始货物规则、实际柜子配置、数量守恒和序列号不重复。单柜两种算法比较仍保留；多柜明确选择一种算法，不混用不同比较结果。
- 每批 200 种规格，最多 50 柜；件数和层数不设 1500 上限。输入、Excel 分组及追加清单校验精确整数范围；求解只生成实际可装件，剩余按数量记账。Worker 增加 fleet 任务和逐柜进度；单柜保护超时 15 秒，多柜有约 90 秒柜间预算和 120 秒保护超时，取消终止当前 Worker 并阻止旧响应覆盖。
- 结果区区分整批与当前柜。切柜重建视图并清理资源；按容器八角投影适配相机，预留工具栏区域。整批 Excel/PDF 使用各柜有效结果生成独立模型图片，包含汇总与逐柜明细；Excel 保留序列号追踪及剩余序列号。
- `modelExport.ts` 从有效排布逐件构建网格并使用 Three.js OBJExporter 导出，不直接导出 InstancedMesh；不使用屏幕显示的微小缩放。当前柜可单独 `.obj`，多柜和可选 `.mtl` 按柜打包；单位为毫米、Y 向上，X 柜长、Z 柜宽，原点为柜内角点。柜体框架可选，辅助网格、灯光和选择框不导出。
- 浏览器保存与 Tauri 原生另存为共用 `saveFile`。本地版本 0.3.0，正式在线站点及下载记录不自动更新。
- 同柜混装继续仅支持同规格对齐堆垛；圆柱按包络估算，不支持交错排列、跨规格上下叠压、真实承重或搬运路径。间隙沿用既有保守可用空间估算，本轮未扩展为支架或搬运的物理仿真。

## 范围
普通干货柜、规则纸箱、单柜多规格混装。中文界面，模拟数据明确标注。
20GP / 40GP / 40HQ 预设仅作参考，可编辑内尺寸、门宽高、最大载重。
浏览器本地使用，不上传业务数据、不需要数据库或账号。

## 坐标与数据
内部毫米、千克。X 从柜内最深处向柜门，Y 沿柜宽，Z 向上；位置为最小角点。
Cargo：id/name/size{x,y,z}/quantity/weight/rotation('upright'|'free')/maxLayers/color。
Container：id/name/size{x,y,z}/door{width,height}/maxWeight。
Placement：boxId/cargoId/containerId/position/size/weight/layer/stackId。
PackingResult：schemaVersion:1/container/cargo/placements/unpacked/strategy/validation。

## 计算边界
首版采用原创保守同规格堆垛＋平面排列启发式，尝试多种货物排序/摆放方向。
每垛相同规格和朝向、底部完整支撑；不跨规格向上叠放。
遵守最大层数、总载重、可用空间、纸箱按摆放朝向通过门宽高的必要条件。
柜门检查不代表完整运动路径验证。不模拟纸箱压溃、绑扎、重心与运输动态。
结果只能称“当前方案未装入”，不声称最优。分层查看不是经验证的装载操作顺序。
计算器与 Three.js 解耦，未来可通过适配器接入 Python 或 Java 开源求解器。

## 界面
清爽工业工具风格：浅灰画布、白色表单、墨绿主操作、低饱和 SKU 配色。
顶部品牌/本地状态/导入导出；左侧柜型和货物清单；右侧统计/3D/结果清单。
表单编辑后标记结果过期，过期结果禁止导出；点击计算才更新。

## v0.2 标准案例与算法比较
新增 7 个有独立手算依据的标准案例及 450 箱虚构业务样例。业务样例不设最优预期，只验证规则。
Worker 支持 pack / compare / suite；当前输入比较限时 15 秒，全套案例在独立 Worker 中限时 30 秒，不改变编辑输入。
compareAlgorithms 为两算法分别复制相同输入，独立计时并重新校验结果及输入一致性。失败结果保留诊断且禁止导出。
MaxRects 使用 MIT maxrects-packer 2.7.3，固定单个柜底，不自动扩柜。4 种排序 × 3 种朝向偏好 × 2 种排布逻辑共 24 次尝试，择优保留已装体积。
二维排布前统一转换为整数网格，通常精度 1e-6mm；自适应尺度保证坐标不超过 1e12，柜底向内、箱底向外量化，吸收整数附近乘法舍入噪声。跨度超出可保留范围时报错，不能假装有效。输出使用原尺寸和还原的毫米坐标，不修改独立校验器。
比较表支持切换 3D 和导出来源；输入修改后标过期，清除标准案例身份，避免修改后的货物冒充手算标准结果。单次耗时不是性能基准，不保证开源算法更优。

## 下一阶段：托盘与装载规则

### 货物形状边界

横放与木包装增补：shape 增加 cylinder-x/cylinder-y/wood-box/wood-frame。横放使用 cylinderDiameter、cylinderLength 表达实际圆柱，size 表达含支架的占位；两套算法只接受固定轴向，不自动水平旋转。圆柱未明确 stackable=true 时默认禁止叠放；允许叠放且未设置 bottomOnly 时，沿用同 SKU、同朝向、上下完整对齐的堆垛，受柜高、最多层数、每垛总重量及总载重限制，不支持交错圆排列。独立校验检查形状尺寸、朝向、地面支撑及堆垛规则。3D 归一化几何保持占位范围，实例化渲染继承选择/分层/导出/资源释放逻辑；木构件厚度、支架样式只作示意，不提供真实承重或固定结构。历史直立模块中的“未支持横放”由本段更新。

2026-09-09 实施：新增 `shape: cylinder` 直立圆柱模式，`size.x = size.y = 直径`、`size.z = 高度`；仅允许 upright，不得同时标记 pallet。排布与独立碰撞检查仍采用方形包络，同一圆柱上下同轴对齐，不声称交错排列或圆形空间优化。Three.js 使用实例化圆柱几何并按原机制释放资源；混装数量按件统计，占位利用率明确区别于实际圆柱体积。圆柱未明确 stackable=true 时默认禁止叠放。独立校验新增叠放、底层与每垛重量检查。后续文本中关于圆柱精确排列的限制仍适用。

长方体纸箱、木箱按外部尺寸计算；不规则货物若已有长方体包装，继续按包装外尺寸计算。裸装机器或不规则木架允许用完全包住货物的最大长方体做保守估算，并配合禁止叠放、只能底层和承重限制。桶、卷材、管材的圆柱排列、可套叠货物、凹槽嵌入和真实异形碰撞不在当前精确模型内；界面应明确显示“按外接长方体估算”。

当前版本定位为纸箱散装装柜的空间估算工具。托盘、易碎货物、局部承重、预留间隙和现场装载顺序尚未实现，界面不得把这些能力描述为已经支持。

下一阶段增加货物形态“纸箱 / 托盘货物 / 整托货物”。托盘货物以托盘连同货物的整体长、宽、高、总重量参与排布，同时保留托盘重量和货物重量字段，便于结果解释。新增规则字段：是否允许叠托、是否允许上方放货、是否只能放底层、托盘最大承重。

装载约束分为四层：

1. **整体限制**：集装箱总载重、货物整体尺寸、柜门必要宽高。
2. **摆放限制**：不可倒置、不可侧放、只能底层、禁止上压、允许或禁止叠托。
3. **承重限制**：托盘最大承重、上方货物重量、易碎货物不得承受上方重量。纸箱抗压能力必须由用户明确提供，未知时不自动推断。
4. **空间预留**：用户可分别设置货物之间、货物与柜壁、货物与柜门的最小间隙。计算时向外预留，不能为了多装而缩小货物尺寸。

结果需要说明每件未装货物的具体原因，例如“柜门宽度不足”“超过总载重”“只能放底层但底层空间不足”“托盘禁止叠放”或“预留间隙后空间不足”。推荐方案只能依据当前规则下的装入数量，不能替代现场确认。

现场装柜顺序和搬运路径另列后续阶段：当前的层数与位置只表示几何布局，不表示人工、叉车或托盘车的实际操作顺序。实现该阶段前需要收集柜门方向、装卸设备、通道需求、允许回转空间和真实装柜记录。
